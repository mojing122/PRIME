## PANTHER 

https://data.pantherdb.org/ftp/downloads/TreeGrafter/

PANTHER19.0

是一个用于研究蛋白质家族、基因功能和基因演化关系的生物信息数据库。

基因节点数据

| 字段            | 含义                             | 可能取值示例及简要说明                                       |
| --------------- | -------------------------------- | ------------------------------------------------------------ |
| `family_id`     | PANTHER 基因/蛋白家族编号        | `PTHR10000`、`PTHR10003`：分别代表两个不同的蛋白家族；编号本身不表示家族间的亲缘远近。 |
| `raw_node_id`   | 节点在当前家族树中的局部编号     | `AN0`、`AN5`、`AN207`：当前家族树中的祖先节点编号，仅在该家族内部有效；数字大小通常不代表演化先后。 |
| `node_id`       | 数据集中的全局唯一节点编号       | `PTHR10000:AN5`：表示家族 `PTHR10000` 中的 `AN5` 节点，通过家族编号和局部节点编号保证唯一性。 |
| `node_type`     | 节点是祖先推断节点还是现代基因   | `ancestral_gene`：根据系统发育树推断的祖先基因，通常为内部节点；`extant_gene`：现存物种中的现代基因或蛋白，通常为叶节点。 |
| `event_type`    | 该节点位置发生的演化事件         | `speciation`：物种分化导致基因分支分开；`duplication`：祖先基因发生复制，形成多个基因拷贝；空值：该节点无事件记录、事件不适用或无法确定，常见于现代基因叶节点。 |
| `species`       | 节点对应的物种或祖先分类群       | `LUCA`：最后普遍共同祖先；`Eukaryota`：真核生物共同祖先或真核生物分类群；`Amoebozoa`：变形虫类共同祖先或分类群；空值：未提供、无法确定或该字段不适用。 |
| `branch_length` | 从父节点到当前节点的序列演化距离 | `0.0`：未检测到明显序列变化或变化极小；`0.029`：较短的演化距离；`1.088`：较长的演化距离、累积序列变化较多；空值：根节点没有父分支，或分支长度未提供。 |



关系数据：

```
PTHR10000:AN11,PTHR10000:AN12,PTHR10000,parent_of,speciation,0.198,PTHR10000.tree
PTHR10000:AN11,PTHR10000:AN17,PTHR10000,parent_of,speciation,0.561,PTHR10000.tree
PTHR10000:AN12,PTHR10000:AN13,PTHR10000,parent_of,duplication,1.125,PTHR10000.tree
PTHR10000:AN12,PTHR10000:AN14,PTHR10000,parent_of,duplication,1.26,PTHR10000.tree
```

| 记录                              | 含义                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `AN11 → AN12, speciation, 0.198`  | `AN11` 是 `AN12` 的父节点；`AN11` 处发生物种分化，从 `AN11` 到 `AN12` 的演化距离为 `0.198`。 |
| `AN11 → AN17, speciation, 0.561`  | `AN11` 同时产生另一个子分支 `AN17`，演化距离为 `0.561`。     |
| `AN12 → AN13, duplication, 1.125` | `AN12` 处发生基因复制，产生子节点 `AN13`，分支长度为 `1.125`。 |
| `AN12 → AN14, duplication, 1.26`  | 同一次基因复制事件还产生了子节点 `AN14`，分支长度为 `1.26`。 |
