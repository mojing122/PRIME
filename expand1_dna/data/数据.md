## PANTHER

https://data.pantherdb.org/ftp/downloads/TreeGrafter/

PANTHER 19.0

PANTHER is a bioinformatics database for studying protein families, gene functions, and evolutionary relationships among genes.

### Gene Node Data

| Field | Meaning | Example values and brief descriptions |
|---|---|---|
| `family_id` | PANTHER gene/protein family identifier | `PTHR10000`, `PTHR10003`: two different protein families. The identifier itself does not indicate the evolutionary proximity of different families. |
| `raw_node_id` | Local node identifier within the current family tree | `AN0`, `AN5`, `AN207`: ancestral-node identifiers valid only within the current family tree. Their numeric order generally does not represent evolutionary chronology. |
| `node_id` | Globally unique node identifier in the dataset | `PTHR10000:AN5`: node `AN5` in family `PTHR10000`. Combining the family identifier with the local node identifier ensures uniqueness. |
| `node_type` | Whether the node is an inferred ancestral node or a modern gene | `ancestral_gene`: an ancestral gene inferred from the phylogenetic tree, usually an internal node; `extant_gene`: a modern gene or protein in a living species, usually a leaf node. |
| `event_type` | Evolutionary event occurring at the node | `speciation`: gene lineages diverge as a result of speciation; `duplication`: an ancestral gene is duplicated, producing multiple gene copies; empty: no event was recorded, the event does not apply, or it cannot be determined, which is common for modern-gene leaf nodes. |
| `species` | Species or ancestral taxonomic group associated with the node | `LUCA`: last universal common ancestor; `Eukaryota`: the common ancestor or taxonomic group of eukaryotes; `Amoebozoa`: the common ancestor or taxonomic group of amoebozoans; empty: not provided, indeterminate, or not applicable. |
| `branch_length` | Sequence-evolution distance from the parent node to the current node | `0.0`: no detectable sequence change or only minimal change; `0.029`: a short evolutionary distance; `1.088`: a longer evolutionary distance with more accumulated sequence changes; empty: the root node has no parent branch, or no branch length was provided. |

### Relationship Data

```text
PTHR10000:AN11,PTHR10000:AN12,PTHR10000,parent_of,speciation,0.198,PTHR10000.tree
PTHR10000:AN11,PTHR10000:AN17,PTHR10000,parent_of,speciation,0.561,PTHR10000.tree
PTHR10000:AN12,PTHR10000:AN13,PTHR10000,parent_of,duplication,1.125,PTHR10000.tree
PTHR10000:AN12,PTHR10000:AN14,PTHR10000,parent_of,duplication,1.26,PTHR10000.tree
```

| Record | Meaning |
|---|---|
| `AN11 → AN12, speciation, 0.198` | `AN11` is the parent of `AN12`. A speciation event occurred at `AN11`, and the evolutionary distance from `AN11` to `AN12` is `0.198`. |
| `AN11 → AN17, speciation, 0.561` | `AN11` also produced another child branch, `AN17`, with an evolutionary distance of `0.561`. |
| `AN12 → AN13, duplication, 1.125` | A gene-duplication event occurred at `AN12`, producing child node `AN13` with a branch length of `1.125`. |
| `AN12 → AN14, duplication, 1.26` | The same gene-duplication event also produced child node `AN14`, with a branch length of `1.26`. |

## Maize Dataset

[MaizeGDB Pedigree](https://github.com/Maize-Genetics-and-Genomics-Database/pedigreenet)

Maize accessions are represented as nodes, and parent–offspring relationships are represented as edges.

| Raw record | Meaning |
|---|---|
| `Country Gentleman,3` | Maize line `3` was derived from, or has as a parent, `Country Gentleman`. |
| `Neal Paymaster,4` | Maize line `4` was derived from, or has as a parent, `Neal Paymaster`. |
| `Country Gentleman,5` | Maize line `5` was derived from, or has as a parent, `Country Gentleman`. |
